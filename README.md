# 🌐 Datacenter - Engineering Suite 2026

## 🚀 Overview

**Datacenter-APP** is a state-of-the-art engineering workspace designed for the mission-critical industry. It integrates **AI-driven analysis**, **3D BIM visualization**, and **precise hydraulic engineering** into a single, high-performance platform.

Designed to replace fragmented spreadsheets, this suite provides a unified environment for designers, engineers, and project managers to plan, calculate, and document datacenter infrastructure with unmatched accuracy and speed.

---

## ✨ Key Features

### 🧠 AI Specification Assistant

- **Automated Parsing**: Instantly extract equipment requirements and pipe segments from project specifications ("Caiet de Sarcini").
- **Smart Suggestions**: AI identifies redundancy needs (N+1, 2N) and suggests appropriate materials based on normative standards.

### 🏗️ Room Preparation & Architecture

- **Phase-based Wizard**: Step-by-step planning for Structure, Fire Protection, Walls, and Fire-Stopping.
- **Normative Integration**: Automatic suggestions based on Romanian standards (e.g., P118, I18).
- **Window Detail Module**: Specialized calculations for insulation and structural support for openings > 1.2m.

### 💧 Hydraulic & Thermal Core

- **Real-time Fluid Dynamics**: Instant calculation of volumes, pressure drops, and pump sizing.
- **Advanced Fluid Support**: Ethylene and Propylene Glycol density interpolation (20°C standard).
- **System Metrics**: Real-time tracking of total system volume, weight, and installed power.

### 📦 BIM & IFC Integration

- **3D Visualization**: Native support for `.ifc` and `.glb` models.
- **Metadata Extraction**: Map BIM parameters directly to hydraulic segments.
- **Spatial Validation**: Sync design data with the engineering calculation engine.

## 📖 Usage Guide

1. **Initialize**: Use the **Start Rapid** template or **Scan BIM** to import your building model.
2. **Configure**: Set your fluid composition (e.g., 30% Glycol) in the Dashboard.
3. **Analyze**: Use the **AI Spec Assistant** to paste your project requirements and generate suggestions.
4. **Engineer**: Detail your pipe segments and equipment in the specialized tabs.
5. **Export**: Generate high-fidelity **PDF Reports** or **BoQ (Excel)** for procurement.
